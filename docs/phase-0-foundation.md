# Part 0: Foundation

## Included

- Next.js 16 App Router, TypeScript, Tailwind CSS 4
- ESLint, Prettier and initial brand color tokens
- Temporary smoke-test Home page and root metadata
- Approved 9-page route inventory and central site configuration
- Empty image asset directories for later phases
- Minimal dependency-free scaffold tests and GitHub Actions workflow

## Not included in Part 0

This patch does **not** recreate the screenshots. High-resolution photography,
brand logo, visual header/footer, actual public pages, ordering, cart, contact
forms, and booking requests belong to later phases. A temporary development
home screen is intentional.

## Input needed before production

- Original logo and high-quality food/interior/event photographs
- Verified menu data with prices and availability
- Verified WhatsApp contact number and location
- Opening hours, delivery area and fees, payment process
- Party capacities, booking policies, production domain

No phone number, prices, delivery fee, booking capacity or hours have been
invented in source code.
